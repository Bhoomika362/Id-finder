## Prerequisites and Setup

### Environment variables

Create a `.env.local` at the project root (used by Next.js and Node):

```bash
OPENAI_API_KEY=
MONGODB_URI=mongodb://127.0.0.1:27017
MONGODB_DB=fuzzy
```

You can also copy from `.env.example`:

```bash
cp .env.example .env.local
```

### Python setup (optional, for fuzzy agent script)

```bash
python -m venv .venv
.\.venv\Scripts\activate  # Windows PowerShell
pip install -r python/requirements.txt
```

Ensure MongoDB is running locally or update `MONGODB_URI`/`MONGODB_DB` to your environment.
